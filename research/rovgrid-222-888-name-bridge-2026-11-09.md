# RovGrid | גשר 222–888: דוד רוב, עמית מייק רוב, ריבועים ופולינום התיבה

## 1. תוצאת השיחה — שני שמות, אותו יחס
**גימטריה רגילה:**
- עמית = 70+40+10+400 = 520.
- מייק = 40+10+10+100 = 160.
- רוב = 200+6+2 = 208.
- עמית מייק רוב = 520+160+208 = **888**.
- דוד = 4+6+4 = 14; דוד רוב = 14+208 = **222**.

**אופרטור הצמצום שנבחר כאן:** מחברים את הספרות של שני הערכים הראשונים בלבד:
- עמית 520 → 5+2+0 = 7.
- מייק 160 → 1+6+0 = 7.
- 7+7 = 14 = דוד.
- רכיב השם רוב נשמר בדיוק, 208 → 208.
- לפיכך [צמצום ספרות של (עמית, מייק)] + רוב = דוד רוב = 222.

זו זהות מותנית באופרטור המפורש: צמצום ספרות של שני רכיבי השם הראשונים תוך השארת השלישי ללא שינוי. אין כאן טענה שצמצום ספרות הוא תכונה של פונקציית הגימטריה המקורית כולה.

## 2. זהות ריבועים — 222 לעומת 888
- 11+10+1 = 22; 11²+10²+1² = 121+100+1 = **222**.
- 22+20+2 = 44; 22²+20²+2² = 484+400+4 = **888**.
- הכפלת כל צלע ב־2 מכפילה כל ריבוע ב־4: 222×2² = 888.
- ריבועים בקנה מידה n: (11n)²+(10n)²+n² = **222n²**.
- n=1 → 222; n=2 → 888; n=3 → 1998; n=4 → 3552; n=5 → 5550.
- 22 הוא גם מניין אותיות האלפבית העברי; 44=26+18, ערך הצירוף "יהוה חי" בגימטריה רגילה. אלו שכבות תיוג סימבוליות נפרדות מההוכחה החשבונית.

## 3. פולינום התיבה המקורי — אימות התלכדות
ל־(a,b,c)=(4,10,13) מוגדר:
- P₁(x) = (1+4x)(1+10x)(1+13x)
- P₁(x) = 1 + 27x + **222x²** + 520x³.
- מקדם x² = 4×10 + 4×13 + 10×13 = 40+52+130 = **222**.
- זהו אותו מספר שמתקבל **בנפרד** מסכום הריבועים 1²+10²+11².

בהגדלה אחידה של שלוש הצלעות פי n:
- Pₙ(x) = (1+4nx)(1+10nx)(1+13nx)
- Pₙ(x) = 1 + 27nx + 222n²x² + 520n³x³.
- n=2: (8,20,26), מקדמים (54,888,4160), והפאות הן (160,208,520).
- n=3: (12,30,39), מקדמים (81,1998,14040).
- **מכאן:** מקדם x² של Pₙ שווה לסכום הריבועים של (n,10n,11n) לכל n, משום ששניהם בדיוק 222n².
- n=3: 1998 = 222×9 = 666×3. הופעת 666 בנוסחת כפל זו אינה הופכת אותו למקדם היסודי של הפולינום: המקדם בבסיס n=1 הוא 222.

## 4. סטטוס יעדי 111, 222, 444, 888
בתנאי a+b=c, ובמספרים שלמים:
- a²+b²+c² = 2(a²+ab+b²), ולכן התוצאה תמיד זוגית: 111 אינו אפשרי.
- 222 אפשרי (a,b,c)=(1,10,11).
- 444 אינו אפשרי: כדי להתקבל נדרש a²+ab+b²=222, אך שארית הביטוי הזה בחלוקה ב־4 יכולה להיות רק 0,1,3; 222≡2 (mod 4).
- 888 אפשרי (a,b,c)=(2,20,22).
- השוויון 222×2=444 קיים בחשבון רגיל, אבל אינו קנה מידה שלם של **משפחת הריבועים** 222n².
- מחיקת הכיתובים Jesus / ΙΗΣΟΥΣ מהעיצוב הסופי נעשתה לבקשת המשתמש; אין להצמיד 888 לשורת 222.
