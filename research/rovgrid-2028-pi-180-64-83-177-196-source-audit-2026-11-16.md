## 2. חישובים הניתנים לשחזור (MATH-EXACT / ENCODING-EXACT)

`YAHUAH`: Y25 + A1 + H8 + U21 + A1 + H8 = **64 = 8²**.
`YAHUSHA`: Y25 + A1 + H8 + U21 + S19 + H8 + A1 = **83**.
`YHWH`: Y25 + H8 + W23 + H8 = **64**.
`FOUNDATION OF HEAVEN`: 6+15+21+14+4+1+20+9+15+14+15+6+8+5+1+22+5+14 = **195**.

מכאן:
- 83 − 64 = **19**, ערך S באנגלית Simple. הערך החדש שקול להוספת S ולשינוי מיקום A בכתיב הנתון.

- 195 = **13 × 15 = 14²−1**.
- 196 = **14²**.
- 177 + 18 = **195** ו־177 + 19 = **196**; מנגנון השלמה שנראה בין המספרים שנבחרו בכרזה. 196−195=1.
- 180 + 1 = **181**, והוא הראשוני ה־42.
- במעלות ורדיאנים: **180° = π רדיאנים**, מפני ש־360° = 2π רדיאנים. אין מכך חישוב של יום־קץ, וגם לא גזירה של π מהטטרגרמטון.
