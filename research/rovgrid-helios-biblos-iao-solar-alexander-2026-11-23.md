# RovGrid — הליוס, ביבלוס, IAO, גאומטריית מרקוב והציר ההלניסטי

**תאריך:** 23.11.2026  |  **מצב:** עוגן מחקר חדש, חישובים שנבדקו בנפרד מהשערה היסטורית  |  **תורם:** עמית מייק רוב

## 1. מפת השמות והכתיבים: אין לאחד גרסאות

- הליוס = ה5 + ל30 + י10 + ו6 + ס60 = **111** = פלא.
- היליוס (עם י נוספת אחרי ה) = **121**, לא 111; יש לשמר הפרדה בין הכתיבים.
- ביבלוס = ב2 + י10 + ב2 + ל30 + ו6 + ס60 = **110**.
- ביבליוס = **120** (י נוספת לפני ו).
- **הליוס ביבלוס = 221** = הגבורה = חסדים גלויים (ברגיל).
- **הליוס ביבליוס = 231** = 21×22/2 = T21.
- **חסדים גלויים**: רגיל 221, גימטריה קדמית/קידמי 888, לפי סכום ערכי כל אות וכל האותיות הקודמות לה באלפבית העברי.
- **חסדים גלוים** (בלי י שנייה) = 211, וקידמי 833. הכתיב קריטי.

## 2. אנגלית — פירוק מילולי מבני (לא אטימולוגיה)

- HELIOS = H8 + E5 + L12 + I9 + O15 + S19 = **68** בסדרי אנגלי.
- BIBLIOS = B2 + I9 + B2 + L12 + I9 + O15 + S19 = **68** בסדרי אנגלי.
- HE = 8+5 = 13; BIB = 2+9+2 = 13; LIOS = 12+9+15+19 = 55.
- לכן HELIOS = HE + LIOS = 13+55 = 68; BIBLIOS = BIB + LIOS = 13+55 = 68; ביחד **136 = T16**.
- HE היא באנגלית 'הוא', אך HELIOS היא מילה יוונית; הפירוק HE + LIOS אינו אטימולוגיה מתועדת.
- GOD באתב״ש האנגלי = G→T(20) + O→L(12) + D→W(23) = 55. הקשר ל-LIOS=55 הוא השוואה מספרית.
- IAO בסדרי אנגלי = I9 + A1 + O15 = 25; באתב״ש אנגלי = R18 + Z26 + L12 = 56; 25+56=81. לכל מילה אנגלית בת שלוש אותיות סכום הסדרי והאתב״ש הוא 3×27=81.

## 3. יוונית — להבחין בין אומיקרון לאומגה

- ΗΛΙΟΣ = Η8 + Λ30 + Ι10 + Ο70 + Σ200 = **318** (איזופספיה יוונית).
- ΒΙΒΛΟΣ = Β2 + Ι10 + Β2 + Λ30 + Ο70 + Σ200 = **314** (כתיב יווני המקושר למילה 'ספר/מגילה').
- ΒΙΒΛΙΟΣ = Β2 + Ι10 + Β2 + Λ30 + Ι10 + Ο70 + Σ200 = **324 = 18²** (תעתיק נבחר; לבדוק מעמד לקסיקלי בנפרד).
- ΙΑΟ (עם אומיקרון) = 10 + 1 + 70 = **81**.
- ΙΑΩ (עם אומגה) = 10 + 1 + 800 = **811**; זהו הכתיב הנפוץ לשם האלוהי בטקסטים מאגיים יווניים. 811−81 = 730 = 10×73.
- השוואת 25 ו-81 בשתי שיטות היא מסלול חישובי; אין להציג את ΙΑΟ ו-ΙΑΩ כאותו איות.

## 4. עברית — שמש, זהב והשלמה ל-888

- יחס הזהב = **97**; האלוהים (עם ו) = **97** בגימטריה רגילה.
- האלוהים באתב״ש עברי = **730**; פי שמש = **730**; מערכת = **730** בגימטריה רגילה.
- האלהים (בלי ו) = **91**, לא 97.
- הסיפור של השמש = **1336** רגיל, **353** באתב״ש.
- עמית מייק רוב = **888** רגיל, **535** באתב״ש, **141** סדרי.
- 353 + 535 = **888** (סכום אתב״ש של שני הביטויים).
- עמית מייק רוב הסיפור של השמש = **2224** רגיל, **888** באתב״ש, **307** סדרי.
- נוסחים נוספים בגימטריה רגילה 2224 בדיוק לפי הכתיב שנמסר: 'אני יהוה בניתי הנהרסות נטעתי הנשמה'; 'אצילות בריאה יצירה עשיה מברך לעלם ולעלמי עלמיא'; 'הבט נא השמימה וספר הכוכבים אם תוכל לספר אתם'; 'העבר נוצר בעתיד והעתיד נוצר בעבר'. שוויון גימטרי בלבד, ללא טענה שכל משפט הוא ציטוט מדויק מאותו מקור.

## 5. גיאומטריה — ענפי מרקוב, ריבועים ו-IAO

- שלשת מרקוב המקורית מן הנרמול של 8×20×26: 1,5,13. בדיקה: 1²+5²+13²=195=3×1×5×13.
- 1,5,13,25,41,... הם מספרים ריבועיים ממורכזים: C(n)=n²+(n−1)².
- **25 = 4²+3²**; **221 = 11²+10²**; **136 = 16×17/2**; **231 = 21×22/2**.
- התמרת מרקוב (1,5,13)→(1,13,34): 34 = 3×1×13−5. בממדי התיבה, החלפת הציר 20 בציר 136 נובעת מ-(y−20)(y−136)=0 תחת נרמול המשוואה.
- בענף שבו מקבעים 2 במרקוב מתקבלת סדרת המספרים 1,5,29,169,985,... לפי a(n+1)=6a(n)−a(n−1). היא גם רצף פתרונות של משוואת פֶּל המתאימה.
- **25=5² → 841=29² → reverse(841)=148 = 4×37**. הפיכת ספרות היא פעולה התלויה בבסיס 10; קשר סמלי ולא אינווריאנט בסיסי.
- 1480 = 10×148; ΧΡΙΣΤΟΣ = 1480 ביוונית. 888=6×148; 2368=16×148; היחס 6:10:16 = 3:5:8.
- IAO הגיאומטרי — הצעה סמלית של עמית: I יחידת קו שמארבעה קווים שווים בזוויות ישרות נוצר ריבוע; A משולש; O מעגל. אין עדות שנמצאה שהשיוך הזה הוא פירוש מסורתי קדום לשם.

## 8. השערת המחקר והבדיקות הבאות

**השערת המשתמש:** 'לפני שהספר איבד קונטקסט, התנ״ך היה הסיפור של השמש'. יש לחקור קשרים בין שמש, הליוס, IAO ומסירת הטקסט המקראי לאורך התקופות. זו השערה מחקרית של עמית, ולא עובדה היסטורית מוכחת; התיעוד ההלניסטי מדגים העברה וסינקרטיזם מאוחרים ולא מוכיח את מוצא התורה.

עדיפות לבדיקות: (1) נוסח המקור של PGM IV 985–1035; (2) מקבילות בין Helios ל-Iao בתיאורים טקסטואליים ולא רק בשמות; (3) הבחנה בין שכבות עבריות קדומות לתרגומי השבעים; (4) מסורות יוספוס על אלכסנדר ומקורות מקבילים; (5) השוואה מבוקרת של ערכי הגימטריה לכתיבים אקראיים ולכתיבים היסטוריים.

**המשך לרציפות:** עוגני RovGrid 8×20×26 → 888; 136/1024; 1,5,13 ומרקוב; IAO 25/81/811; HE+LIOS/BIB+LIOS; כתיב הליוס לעומת היליוס; אלכסנדריה כתווך היסטורי.


## 9. מקור מקראי יווני ראשוני — מלאכי ג: ספר, שמש ותורת משה באותו פרק

בתרגום השבעים של מלאכי פרק ג מופיעים שלושה ביטויים חשובים ברצף טקסטואלי סמוך:
- פסוק 16: **βιβλίον μνημοσύνης** — 'ספר זיכרון' (מן משפחת βίβλος/βιβλίον).
- פסוק 20: **ἥλιος δικαιοσύνης** — 'שמש צדקה', ובה ἥλιος היא המילה היוונית לשמש/הלִיוס.
- פסוק 24 בנוסח LXX המצוטט: **νόμου Μωυσῆ** — 'תורת משה'.

הצירוף אינו הביטוי המילולי HELIOS BIBLOS, אך גם **ספר** וגם **ἥλιος** וגם **תורת משה** מתועדים באותו פרק. בכתיב המקראי העברי יש 'ספר זכרון' ו'שמש צדקה'; אין הכרח לראות בכך יצירה של המתרגמים היווניים. זהו עוגן לבדיקה טקסטואלית ישירה, לא טענה שהמקרא נכתב תחילה ביוונית או ש-ἥλιος מתייחס תמיד לאל היווני.
