# הצטרפות לשעון הראשוניים

כל מחשב יכול לתרום חישובים — אין צורך לתת הרשאות למאגר הראשי.

1. עושים **Fork** למאגר ומורידים למחשב.
2. פותחים תיקייה `prime-clock-network`. צריך Python 3.11 ומעלה. להאצת בדיקות גדולות מומלץ להתקין `gmpy2`.
3. בוחרים משימה מקובצי `jobs/`, ומוודאים ב־Issues שהיא עדיין לא נתפסה על ידי מתנדב אחר.
4. מריצים:

```bash
python3 prime_clock.py run --job jobs/g09-000348-000448.json --worker volunteer1 --seconds 600
```

5. הקופסה רצה למשך עד עשר דקות *ועשויה לחרוג מעט אם מבחן מודולרי יחיד מתארך*. אפשר לעצור ולהריץ אותה שוב עם אותם פרמטרים.
6. בכל סיבוב שהושלם נשמרת שורה בקובץ `contributions/*.jsonl`. חישוב שנקטע באמצע יחזור בפעם הבאה; לא נאבד סיבובים שהושלמו.
7. שולחים את קובץ התוצאה ב־Pull Request. הבודק בוחן את המבנה ואת תעודות הראשוניות; תוצאות שליליות דורשות אימות נוסף לפני הכרזתן כסריקה מלאה ומוכחת.

## הכללים

- `S` — קיים גורם קטן; `C` — המספר פריק לפי כישלון מבחן פרמה; `U` — לא הוכרע; `P` — תעודת ראשוניות מועמדת.
- רק תעודה מאומתת עוברת לקורפוס המוכח. גם טעויות, אי־הכרעות ותוצאות שחוזרות על עצמן נשמרות בארכיון המחקר.
- העיבוד מבוצע על מחשב המתנדב. GitHub אינו מפעיל סריקת רקע רציפה מעצמו.
- מומלץ לבחור שם כינוי אנונימי; אין להעלות מפתחות, כתובות או פרטי מחשב.
- בשלב הפיילוט, ארבע המשימות מתחילות מאינדקס 348. ייתכן שהן חופפות לחישובים קודמים, אבל הן מאפשרות בדיקה בלתי תלויה של התוצאות.

שיא העולם אינו מובטח; הרשת אמורה לאפשר לנו לנצל מחשבים נוספים ולמדוד בכנות את העלות של כל דור.
