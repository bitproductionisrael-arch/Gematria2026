# ASI — Algorithmic Structure Index, WORK/JUDGE v1 (2026-11-24)
Purpose: quantify reproducible structure and predictive utility, not probability of AI, divine authorship, nonhuman origin, or personal identity. No reward for positive outcomes; negative/null results are retained. No single 0–100 score until calibrated against independent matched reference corpora.
Sources: Shannon 1948 https://doi.org/10.1002/j.1538-7305.1948.tb00917.x ; NIST runs test https://www.itl.nist.gov/div898/handbook/eda/section3/eda35d.htm ; Hemerik & Goeman exact permutation https://doi.org/10.1007/s11749-017-0571-1 ; Rissanen MDL https://www.scholarpedia.org/article/Minimum_description_length ; Grünwald tutorial https://arxiv.org/abs/math/0406077 ; Krichevsky–Trofimov https://doi.org/10.1109/TIT.1981.1056331 ; holdout https://scikit-learn.org/stable/modules/cross_validation.html ; Bible-code selection criticism https://openresearch-repository.anu.edu.au/items/40262bdb-e7e3-47df-bdcf-10dab4e212b5 .
Implementation is an original adaptation, not copied source code or a certified NIST test suite.
T1: empirical Shannon letter entropy and exact conditional binary runs p (absolute deviation from expectation), ordinal symbols 1..22 or 1..26 in 5-bit words, finals normalized. Conditional null is uniformly arranged bits at fixed counts; natural encoded language violates it, so p not evidence of authorship. Compare matched language/length/encoding, not IID bits, in prospective study.
T2: exact word-order permutation of adjacent regular-value pairs (English A1Z26); count outputs of +, absolute difference, XOR, AND, OR in frozen target list in ASI-v1-pilot.js; count equal operation results with multiplicity in this pilot; all labeled permutations up to 8 words. This checks order only, not invariant sums; longer input N/A pending fixed Monte Carlo extension. Target set learned from existing corpus, not independent. For numerical-only results define appropriate control by operation and source, preserve dependent outputs; do not pretend a text test applies to a number.
T3: illustrative two-part MDL ideal code lengths conditional on known alphabet and length, uniform vs adaptive KT unigram and order-1 Markov; 2-bit model selector if choosing among 3; compared to same tagged uniform, gain equals uniform minus best model. Compared with untagged uniform, subtract 2 bits. Not actual file compression. Future compare matched human baselines and explicit code costs of arithmetic rules (including targets/maps/selection).
T4: train KT unigram on first floor(n/2) letters, freeze probabilities, score remaining letters by log loss vs uniform; existing examples are retrospective. Prospective: register claim/version, input selection, exact rule/encoding, target, comparator, metric, stopping, and full multiplicity family in immutable file BEFORE retrieving unseen text. Use held-out passages and matched human texts of same genre, length, language, edition; synthetic matched controls as secondary only. Evaluate against learned human-language baseline, not just uniform. Keep failure denominator. Holm correction for prespecified family; distinguish explorations. Avoid reusing test set.
