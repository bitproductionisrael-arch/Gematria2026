## Twelve work packages
1. Q10 bijection: two disjoint 8^3 voxel grids map to ten-bit labels s||bin3(x)||bin3(y)||bin3(z). The bijection alone does not preserve adjacency. Q10 has 5120 edges; disjoint grids have 2688.
2. Gray embedding: g(t)=t XOR (t>>1) replaces each 3-bit coordinate; g(t),g(t+1) differ by one bit. In ordinary binary only 1536 edges overlap; 1152 grid edges are not Q10 edges and 3584 Q10 edges are not grid edges. With Gray all 2688 grid edges are preserved, 2432 additional hypercube edges remain, including 512 selector edges. This is a subgraph, not an isomorphism.
3. Cuboid audit: exactly 16 positive sorted integer triples satisfy ab+ac+bc=888. For fixed a<=b<=c, a<=floor(sqrt(888/3))=17 and c=(888-ab)/(a+b); finite scan. Adding a+b+c=54 leaves only (8,20,26) and (10,16,28). Full enumeration in verifier. Existing twin result strengthened by explicit counterfamily.
